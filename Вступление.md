## 1. git и GitHub
На этом курсе свои решения вы должны будете выкладывать на **самый популярный хостинг свободных проектов GitHub**, и присылать в форме ответа прямую ссылку на ваш файл с решением, размещённый на гитхабе.

GitHub подразумевает не просто хранение файлов: это прежде всего **система версионного контроля кода**.

[Ознакомительный материал про версионный контроль исходных текстов.](https://skillsmart.ru/self/ea41.html)

Версионный контроль исходных текстов на GitHub выполняется с помощью самой популярной системы контроля версий кода **git**.

Пройдите [этот бесплатный курс по git-у](https://ru.hexlet.io/courses/intro_to_git)
+ [уточняющие рекомендации](https://htmlacademy.ru/blog/187-git-console)
+ [обучающая игра](https://learngitbranching.js.org/)
+ [учебник](https://git-scm.com/book/ru/v2)

Можно использовать графические клиенты к гитхабу, есть родной [desktop.github.com](https://desktop.github.com/)
или например очень популярный [TortoiseGit](https://tortoisegit.org/)

Сам git (**командную строку**) изучайте постепенно в фоновом режиме, это обязательная вещь на любой программистской работе.

[Памятка по Git](https://skillsmart.ru/self/baza/git.html)

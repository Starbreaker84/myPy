### 4.1 Пример композиции для двух иерархий классов
Предыдущие реализации плохо подходят для демонстрации, поэтому сделаем новые иерархииб навеянные книгами о Гарри Поттере.
Заклинания и магические артефакты, которые сможет использовать волшебник.
```python
class Spell:
    def cast(self):
        pass

    def cancel(self):
        pass


class FireSpell(Spell):
    def ignite(self):
        pass

    def create_smoke(self):
        pass


class IceSpell(Spell):
    def freeze(self):
        pass

    def make_slippery(self):
        pass

class Artifact:
    def activate(self):
        pass

    def recharge(self):
        pass


class Ring(Artifact):
    def become_invisible(self):
        pass

    def whisper(self):
        pass


class Staff(Artifact):
    def amplify_magic(self):
        pass

    def summon_light(self):
        pass
```

Пример самой композиции. Волшебник имеет "слоты" для заклинаний и артефактов.
```python
class Wizard:
    def __init__(self, spell: Spell, artifact: Artifact):
        self.__spell: Spell = spell
        self.__artifact: Artifact = artifact

    def attack(self):
        self.__artifact.activate()
        self.__spell.cast()
```

### 4.2 Два вида полиморфизма.

Полиморфизм подтипов - когда мы можем определить по разному одно и тоже поведение объектов в одной иерархии. Например "полать голос" для кота и собаки - сигнатуры методов будут одинаковы, а вот "эффект" свой для каждого реального типа объекта.

Стоит так же упомянуть ad hoc полиморфизм - он схож с полиморфизмом подтипа, но позволяет определять несколько реализаций одноого и того же метода в зависимости от его списка параметров. Напрмер котик может подавать голос обычно, или при наличии параметра "опасность" начать шипеть.

Параметрический полиморфизм - когда метод может работать с любым входящим типом параметров. Так, например, мы могли бы отдать команду голос около забора, а за забором, обученные на эту команду котик, собака и птица каждый издал бы свой собвственный звук, при этом для нас, как для "метода" не имеет значения какое конкретно животное услышало нашу команду.

### 4.3 Разбор примера со списком list[Animal]

При каждом вызове функции foo() мы случайным образом будем получать строки "Кошка мурлычет" или "Птица поет", это будет полиморфизм подтипов.
А вот сама возможность итерироваться по "просто животным" и работать с ними всеми одним методом - это уже параметрический полиморфизм.
